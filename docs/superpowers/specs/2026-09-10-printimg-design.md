# PrintImg 설계 문서

작성일: 2026-09-10

## 1. 목적

이미지 파일 하나를 골라 A4 세로 용지 기준의 다중 페이지 PDF로 만드는 Windows 데스크톱 프로그램.
세로로 긴 화면 캡처(예: Google Forms 응답 화면 전체 캡처)를 종이로 뽑는 용도가 주 목적이다.

## 2. 요구사항

- Python + Tkinter GUI, PyInstaller로 단일 exe 배포 (옆 프로젝트 `stayAwake`와 같은 방식).
- 이미지 선택 → 옵션 지정 → PDF 생성 → 기본 PDF 뷰어로 자동 열기. 프린터로 직접 보내지 않는다.
- 가로 크기 규칙
  - 기본(폭 맞춤): 이미지 폭을 인쇄 가능 영역 폭에 100% 맞춘다. 작으면 확대, 크면 축소.
  - "원본 크기 유지" 옵션: 원본 1 px = 1/96 inch로 보고 실제 크기로 출력한다. 이 크기로 폭이 넘치면 폭 맞춤으로 자동 전환한다.
- 세로 크기 규칙: 한 페이지를 넘는 높이는 여러 페이지로 이어서 출력한다. 자르는 위치는 페이지 경계 근처의 빈 줄(단색 가로줄)을 우선하고, 없으면 등분한다.
- 여백: 사용자 옵션, 네 변 동일, 0~30 mm, 기본 10 mm.
- 미리보기는 없다. 확인은 생성된 PDF를 뷰어에서 본다.

### 범위 밖 (v2 후보)
- 프린터로 직접 인쇄
- 창 안 미리보기 및 분할 경계 수동 조정
- 가로 방향 용지, A4 외 용지

## 3. 구조

```
printImg/
├── src/
│   ├── main.py        # Tkinter GUI, 진입점

│   ├── paginate.py    # 순수 로직: 배율 계산 + 분할 위치 결정
│   └── pdf_writer.py  # 조각을 A4 캔버스에 얹어 PDF 저장
├── tests/
│   ├── test_paginate.py
│   ├── test_image_loader.py
│   └── test_pdf_writer.py
├── docs/superpowers/specs/

```

### 모듈 책임

| 모듈 | 입력 | 출력 | 모르는 것 |
|---|---|---|---|
| `paginate` | 이미지 크기, 옵션, (빈 줄 탐지용) 이미지 객체 | `Plan` (배율, 가로 오프셋, 구간 목록) | Tkinter, 파일 I/O |
| `pdf_writer` | 이미지, `Plan`, 출력 경로 | PDF 파일 | 분할 규칙 |
| `image_loader` | 파일 경로 | RGB 이미지 (EXIF 회전 적용, 투명도 흰 배경 합성) | 분할 규칙, GUI |
| `main` | 사용자 조작 | 위 셋의 호출 | 계산 세부 |

### 데이터 흐름

1. `main`이 파일 대화상자로 경로를 받고 옵션을 읽는다.
2. `image_loader.load_image(path)`가 이미지를 로드하고 전처리한다 (EXIF 회전 적용 → RGBA는 흰 배경에 합성 → RGB 통일).
3. `paginate.plan(image, options)`가 `Plan`을 돌려준다.
4. `pdf_writer.write(image, plan, out_path)`가 PDF를 저장한다.
5. `main`이 `os.startfile(out_path)`로 PDF를 연다.

출력 파일은 원본과 같은 폴더의 `<원본이름>.pdf`. 이미 있으면 덮어쓸지 묻는다.

## 4. 크기 계산 (`paginate`)

상수:
- A4 = 210 × 297 mm
- 출력 해상도 = 300 DPI → 캔버스 2480 × 3508 px
- 원본 픽셀의 가정 밀도 = 96 DPI (원본 크기 모드에서만 사용)

계산:
- `usable_w = round((210 − 2·margin_mm) / 25.4 × 300)`, `usable_h`도 같은 식으로.
- 배율 `scale` (원본 1 px → 출력 px)
  - 폭 맞춤: `scale = usable_w / img_w`
  - 원본 크기: `scale = 300 / 96 = 3.125`. 단 `img_w × 3.125 > usable_w`이면 폭 맞춤으로 전환.
- 가로 오프셋: 폭 맞춤은 0, 원본 크기 모드는 `(usable_w − img_w × scale) / 2` (가운데 정렬).
- 한 페이지에 들어가는 원본 높이 `page_h = floor(usable_h / scale)`.

검산 (샘플 1920 × 6308, 여백 10 mm, 폭 맞춤): usable_w 2244, scale ≈ 1.169, page_h ≈ 2799, 예상 3페이지.

## 5. 분할 알고리즘 (`paginate`)

모든 좌표는 원본 픽셀 기준.

빈 줄 판정:
- 그레이스케일로 변환 후 각 가로줄의 (최댓값 − 최솟값)을 구한다.
- 이 값이 `BLANK_THRESHOLD = 8` 이하이면 빈 줄. 배경색이 무엇이든 단색이면 빈 줄로 본다.
- 필요한 줄만 계산한다.

자르기 (페이지마다 반복):
1. 현재 시작 `y0`, 이상적 끝 `y_ideal = y0 + page_h`. 남은 높이가 `page_h` 이하면 끝까지 담고 종료.
2. `y_ideal`에서 위로 올라가며 첫 빈 줄을 찾는다. 탐색 범위는 `page_h × SEARCH_RATIO`, `SEARCH_RATIO = 0.3`. 아래로는 찾지 않는다 (넘침 방지).
3. 찾으면 그 줄에서 자른다. 콘텐츠 바로 아래 여백이므로 다음 페이지는 빈 줄 한 줄로 시작한다.
4. 못 찾으면 `y_ideal`에서 자른다 (등분 폴백).

결과: `[(y_start, y_end), ...]`. 구간은 이어지고 겹치지 않으며 마지막 `y_end == img_h`. 마지막 구간은 짧을 수 있다.

알려진 한계: 빈 줄 한 줄만 있어도 자르므로 줄 간격이 좁은 본문 중간에서 잘릴 수 있다. 더 정교한 선택(가장 긴 여백 우선 등)은 이 함수 하나만 바꾸면 된다.

## 6. PDF 출력 (`pdf_writer`)

- 페이지마다 2480 × 3508 흰 RGB 캔버스를 만든다.
- 구간마다 원본에서 조각을 잘라 `(round(img_w × scale), round(slice_h × scale))`로 LANCZOS 리사이즈한다. 원본 전체를 미리 확대하지 않는다.
- 높이는 `usable_h`로 클램프한다 (반올림 오차 1 px 대비).
- 캔버스의 `(margin_px + x_offset, margin_px)`에 붙인다 (위쪽 정렬).
- Pillow의 다중 페이지 PDF 저장(`save_all=True`, `resolution=300`)으로 한 파일에 쓴다. 뷰어에서 정확히 A4로 잡힌다.

## 7. GUI (`main`)

화면 (위에서 아래로):
1. `[이미지 선택…]` 버튼 + 선택된 파일명과 크기 (예: `foo.png · 1920 × 6308`)
2. `☐ 원본 크기 유지`
3. `여백 (mm)` 스핀박스 0~30, 기본 10
4. `[PDF 만들기]` 버튼. 파일 선택 전에는 비활성
5. 상태줄. 완료 시 "3페이지 생성 → foo.pdf"

지원 형식: PNG, JPG/JPEG, BMP, GIF(첫 프레임), WEBP. 파일 대화상자 필터도 동일.

처리 중: 메인 스레드에서 실행. 버튼 비활성, 대기 커서, 상태줄 "처리 중…". 샘플 크기 기준 2~3초.

## 8. 오류 처리

모두 메시지 박스로 알리고 창은 유지한다.

| 상황 | 동작 |
|---|---|
| 손상·미지원 파일 | "이미지를 열 수 없습니다" + 파일명 |
| 출력 PDF 이미 존재 | 덮어쓸지 예/아니오 |
| 출력 PDF가 열려 있어 쓰기 실패 (`PermissionError`) | "PDF가 열려 있습니다. 닫고 다시 시도하세요" |
| Pillow 픽셀 한도 초과 (`DecompressionBombError`) | "이미지가 너무 큽니다". 한도는 기본값 유지 |
| PDF 자동 열기 실패 | 저장 경로만 안내, 오류로 취급하지 않음 |

경계 입력: 높이가 한 페이지 이하면 1페이지. 여백 30 mm에 원본 크기 모드로 폭이 넘치면 폭 맞춤 전환.

## 9. 테스트

pytest. 테스트 이미지는 파일 없이 Pillow로 코드 안에서 생성한다.

`test_paginate.py`
- 배율: 폭 맞춤에서 `img_w × scale == usable_w`. 원본 크기 모드에서 좁은 이미지는 3.125, 넓은 이미지는 폭 맞춤 전환.
- `page_h`: 여백 0 / 10 / 30 각각 기대값.
- 빈 줄 판정: 흰 줄·회색 단색 줄은 빈 줄. 흑백 혼합 줄, 임계값 바로 위 노이즈 줄은 아님.
- 한 페이지: 높이 ≤ `page_h`면 구간 하나.
- 빈 줄 발견: 검은 띠 사이 흰 줄이 있는 합성 이미지에서 이상 위치 위쪽 흰 줄에서 잘림.
- 폴백: 전부 노이즈면 정확히 `page_h` 간격 등분.
- 탐색 범위 밖: 빈 줄이 30%보다 위에만 있으면 무시하고 폴백.
- 구간 무결성: 이어지고 겹치지 않으며 마지막 끝이 이미지 높이.

`test_pdf_writer.py`
- 페이지 수: 구간 3개 → PDF 프레임 3장 (Pillow로 다시 열어 확인).
- 페이지 크기: 2480 × 3508.
- 배치: 여백 10 mm에서 콘텐츠 좌상단이 (118, 118) 근방. 마지막 짧은 페이지 하단은 흰색.
- 가운데 정렬: 원본 크기 모드에서 좁은 이미지가 좌우 대칭.
- RGBA 입력: 투명 영역이 흰색.

수동 확인 (README 체크리스트)
- `_data` 샘플로 3페이지 PDF 생성, 뷰어 자동 열림
- 차트 중간이 아닌 카드 사이 여백에서 잘렸는지 확인
- 덮어쓰기 확인창, 열린 PDF 쓰기 실패 메시지
- exe 빌드 후 Python 없는 환경에서 실행
